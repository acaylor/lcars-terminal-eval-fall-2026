## Source inspection notes (file:line)

### Architecture & main loop
- `cmd/lcars/main.go:14-56`: flag validation with actionable messages, then dispatch to `app.Capture`, `app.Snapshot` or `app.Run`.
- `internal/app/app.go:52-133`: `Run` installs signals before raw mode (54-56), defers `session.Close` (61), runs an input goroutine (82-101) and a select loop over signals, ticker, keys and input errors (104-132). Collection goes through `controller.collect` (28-36) and key handling through `controller.key` (37-51).
- `internal/ui/view.go`: the pure `Draw(w,h,snapshot,state) *Canvas` (18-33) picks a tier: tiny <78×24, compact <105×34, large otherwise. `internal/ui/canvas.go` holds the cell grid, text sanitizing and SVG export.
- `internal/terminal/render.go:59-95`: ANSI cell-diff renderer working against the previous canvas. `terminal.go` holds the termios session and color detection.
- Layering note: `terminal` imports `ui` because the renderer consumes `*ui.Canvas`. This is acceptable.

### OS collector interface & macOS backend
- Interface: `type Collector interface{ Collect(processes bool) Raw }` (metrics.go:51). Backends return raw counters only. All rate math lives in the OS-independent `Sampler` (metrics.go:70-141).
- Linux (collector_linux.go): `/proc/uptime`, `loadavg`, `stat` (parseCPUs, guest not double-counted, 117-143), `meminfo`, `syscall.Statfs("/")` (84-90), `net/dev` without `lo` (160-185), `/proc/<pid>/stat` with rparen-safe comm parsing (186-207). AT_CLKTCK comes from `/proc/self/auxv` (26-45).
- macOS (collector_darwin.go, cgo, built natively OK):
  - Uptime: `sysctlbyname("kern.boottime")` + `gettimeofday` (36-39).
  - Load: `getloadavg` (40).
  - Memory: `hw.memsize` (42). `host_page_size` + `host_statistics64(HOST_VM_INFO64)` give available = free+inactive (43-48).
  - CPU: `host_processor_info(PROCESSOR_CPU_LOAD_INFO)` with uint32 tick casts, aggregate in slot 0 (49-58). `vm_deallocate` size is `ninfo*sizeof(integer_t)`, which is correct. The host port is deallocated (59).
  - Swap: `vm.swapusage` → `xsw_usage` (60-61).
  - Disk: `statfs("/")` (62-63).
  - Network: `getifaddrs` AF_LINK `if_data` ibytes/obytes excluding loopback (64-73). These are **32-bit legacy counters**. The README discloses that they can roll over (README.md:169-170), and a wrap turns into one N/A interval.
  - Processes: `proc_listallpids` sized in bytes, which is correct (75-79). `proc_pid_rusage(RUSAGE_INFO_V2)` (82), `proc_name` (85).
  - **Defect:** `ri_user_time + ri_system_time` are divided by 1e9 as if they were ns (Go side :167). On arm64 they are `mach_absolute_time` ticks (24 MHz timebase, 125/3 ns per tick), and no `mach_timebase_info` conversion is done. The native capture shows svc03 0.1% / svc39 0.1% while the same-moment `top` reference shows 4.2% / 2.2%, a ratio of about 42 that matches 125/3. Ranking stays correct and magnitudes are wrong.
  - Struct handling: each `native_sample` is copied by value and C allocations are freed by `native_free`. `unsafe.Slice` uses C-reported lengths. A calloc failure leaves the flags unset and the metric unavailable. Passing a Go pointer to `native_free` is allowed by the cgo rules because the struct holds only C pointers.
- `collector_darwin_nocgo.go:9-12`: when built with `CGO_ENABLED=0`, every metric is unavailable and an Issue explains why. This is a documented degraded build, not a hidden stub. The release macOS build uses cgo.

### Forbidden-subprocess check
- `grep exec.|os/exec|Command(|popen|system(` over `cmd/` and `internal/` finds nothing. static-scan SUBPROCESS=0. `subprocess` appears only in `scripts/measure.py`, the measurement harness.

### Rate math & robustness edge cases
- `dt` comes from `r.At.Sub(s.previous.At)`, where `time.Now()` carries a monotonic reading (metrics.go:72). All rates are guarded by `dt > 0` (73, 111).
- `Delta` returns invalid for elapsed ≤0, NaN, Inf or `after<before` (58-63). `utilization` returns invalid when total does not increase or busy decreases (64-69).
- Interfaces are matched by name, so new or vanished interfaces never spike the rate (82-100). PID reuse is caught by comparing start time (`Identity`) (111). Vanished PIDs drop out.
- The baseline owns copies of slices and maps (129-138).
- A very long dt yields a correct average rate (tested with dt=1000).
- Permission errors: an unreadable `/proc/<pid>/stat` is skipped while still counted (collector_linux.go:103-107). Darwin `proc_pid_rusage` failures are skipped (82).
- Unicode: `Safe` drops control, Cf, Mn and Me runes and maps wide runes (East Asian and emoji ranges) and U+FFFD to `?`. `Truncate` clips by rune count with a `~` marker, which is width-correct because only single-width runes survive (canvas.go:74-100). Hostname is clipped to 25 on the primary view (view.go:199) and process names to `W-x-40` (view.go:323).

### unsafe / FFI / panic audit & bounded memory
- Go `unsafe` appears only in the termios/winsize ioctl wrapper (terminal.go:18-29, 35, 48, 62). It uses the `uintptr(arg)` conversion inside the `Syscall` call and correctly sized `syscall.Termios` and 4×uint16 winsize structs. Sound.
- The cgo block is sound in memory terms but crammed into dense one-line statements with a single explanatory comment (collector_darwin.go:46). The time-unit error is above.
- Panic path: Go panics on the main goroutine run deferred `session.Close()` (app.go:61), which restores termios and emits `0m ?7h ?25h ?1049l` (terminal.go:57-64). There is no `recover`, so the process still prints the panic after restoring. The input goroutine only calls `os.Stdin.Read`.
- Bounded memory: CPU history is capped at 160 (app.go:31-35, tested). Top-5 is sliced (metrics.go:126-128). Canvas size is clamped to 500×200 (canvas.go:41-42). The process baseline is proportional to the live process count.
- SIGTSTP is not handled. The README discloses that job-control suspension is unsupported (README.md:181-182).

### Test quality & determinism
- metrics_test.go: `TestDelta` is a 7-case table. `TestSamplerIntervalsHotplugAndPIDReuse` covers measured dt=2 s, interface appear/vanish, PID identity change and counter reset. `TestSamplerZeroElapsedTopFiveAndRecovery` covers dt=0, the top-5 bound and recovery after 20 s.
- collector_linux_test.go: parser fixtures cover guest exclusion, kB scaling, lo exclusion and a comm containing `) λ`, plus malformed rejects. `TestCollectorFailureIsolation` uses a temp-dir fake `/proc`. `TestLiveLinuxCollector` is host-dependent but only checks for presence.
- render_test.go: cell diff (0 bytes on an identical frame; a 1-cell change stays under 10% of the initial size with no 2J; resize triggers 2J) and reduced-color SGR with no truecolor leak, plus env detection.
- view_test.go: 8 sizes (1×1 to 500×200) × diag/help/ascii, checking grid dimensions, ASCII purity and no escapes. Composition checks blank ≥20%, the process list absent from primary and present in secondary, and the 80x24 labels. Also `Safe`, valid SVG XML and a fuzz seed.
- app_test.go: key handling (pause, view switch while paused, Tab, quit keys) and the 160-entry history bound.
- Gap: no assertion that the tier switches at 78×24 or 105×34, and no test of the macOS collector. That collector is untestable on Linux, but it builds and its tests pass natively.

### Scope discipline
- No config files, mouse, themes, plugins or process actions. Extra flags are `--interval` (500 ms to 10 s), `--snapshot`/`--diagnostic` (documented non-TTY mode) and `--capture` (deliverable captures). None is bloat in the sense of the prompt.
