## Source inspection notes (file:line)

### Architecture & main loop
- main.rs:201-243 handles only argument dispatch. `AppController` (app.rs:257-448) owns the collector, sampler, UiState and both canvases. `run_interactive` (app.rs:385-432) is a short poll→apply_event→sample→render loop with a ≤250 ms poll cap, so there is no busy-wait.
- `apply_event` (app.rs:309-357) is a pure state transition. Rendering (ui.rs `render_ui` 135-163) takes `&SystemTelemetry` + `&UiState` and draws into a headless `Canvas`; canvas.rs:785-828 does the diffing.
- ui.rs is 1,829 lines with long functions built on absolute coordinates (e.g. render_full_primary 607-1180). It holds together but is oversized.

### OS collector interface & macOS backend
- Trait at collector/mod.rs:234-236. `create_platform_collector` (240-252) is the only cfg branch point. Shared POSIX helpers: localtime_r (296-317), gethostname (320-334), uname (337-371), getloadavg (374-382), statvfs (386-407).
- Linux (collector/linux.rs): /proc/uptime, /proc/stat (185-232, includes steal/irq/softirq, iowait counted as idle), /proc/meminfo with a MemAvailable fallback (235-291), /proc/net/dev excluding lo (294-317), /proc/[pid]/stat parsed via rfind(')') (321-367). Processes are scanned only when the diagnostics view is open (124-128).
- macOS (collector/macos.rs), line by line:
  - Uptime: `sysctl(CTL_KERN, KERN_BOOTTIME)` into a `timeval`, size checked (120-144). Correct; matches the reference across the DST change (6d 18:41:37).
  - CPU and per-core: `host_processor_info(PROCESSOR_CPU_LOAD_INFO)`, 4 ints per CPU in USER/SYSTEM/IDLE/NICE order, then `vm_deallocate` with the right byte length (146-175). Sound.
  - Memory: `HW_MEMSIZE` u64 (178-196). `host_statistics64(HOST_VM_INFO64, HOST_VM_INFO64_COUNT)` gives available = free+inactive+purgeable pages × the sysconf page size, which is 16 KiB on arm64 (198-220). Displays 10.6 GiB available vs 10.55 computed from vm_stat. Correct. `compute_macos_vm_memory` (56-69) has a redundant `max` expression but returns the right result.
  - Swap: `VM_SWAPUSAGE` into `xsw_usage` (222-240). Correct; 0 on the host.
  - Disk: shared statvfs. Used = total − bfree, so it counts the whole APFS container (283.0/460.4 GiB; df avail 177.5 GiB matches).
  - Network: `getifaddrs`, AF_LINK, non-loopback, `if_data.ifi_ibytes/obytes` (245-275). These are **32-bit** counters (wrap at 4 GiB). `counter_delta` (sampler.rs:261-280) compensates with a 32-bit wrap heuristic. NET_RT_IFLIST2 64-bit counters are not used.
  - Processes: **bug at 279-283.** `proc_listallpids(NULL,0)` returns a PID *count*, not bytes. The code divides it by `size_of::<pid_t>()` again and adds 64, so the buffer holds about n/4+64 PIDs and the enumeration is cut short. macOS capture: "297 ACTIVE TASKS" vs reference `process_count` 915. The top-5 (svc03 7 %, svc02, …) misses mediaanalysisd at 64 % and svc39 at 8.9–34.5 %. Not memory-unsafe (the buffer length passed matches the allocation), but the data is wrong. `proc_pidinfo(PROC_PIDTASKALLINFO)` with a size check (300-311) and the mach-time→ns conversion via `mach_timebase_info` (100-108, 329-336) are correct. pid 0 (kernel_task) is skipped (297).
  - Uses deprecated `libc::mach_host_self`/`mach_timebase_info`, which causes 6 warnings in macos-build-release.log and 6 errors in clippy-darwin-deny.log.

### Forbidden-subprocess check
- static-scan SUBPROCESS = 0. Grepping for `Command::new`, `popen` and `system(` finds no hits. Time comes from localtime_r and hostname from gethostname. **Clean.**

### Rate math & robustness edge cases
- dt is measured with `Instant::saturating_duration_since` (app.rs:295-300). The sampler accepts dt in [1 ms, 120 s] and gives a rate of 0 outside that range, so no NaN or Inf (sampler.rs:10-11,38-39,146-153).
- Net: the delta is summed only over interfaces present in both samples, so a new interface causes no spike and a vanished one is dropped (sampler.rs:133-144). Counter decrease: a 32-bit wrap below 512 MiB is accepted, anything else counts as a reset and gives 0 (261-280). Small risk: a 64-bit counter that resets from a value under 4 GiB can produce a made-up delta of up to 512 MiB.
- CPU: `utilization_delta` returns None on decrease or zero d_total and falls back to the last value (model.rs:298-311; sampler.rs:42-43). The first sample uses the since-boot ratio, and the 25 ms warm-up (app.rs:390-392) supplies a real delta for the first frame.
- Processes: keyed by PID and name, so PID reuse resets to 0 (sampler.rs:168-177). `prev_procs` is replaced wholesale, so vanished PIDs are freed (200-201). Unreadable /proc/PID/stat entries are skipped (linux.rs:76-79). macOS skips PIDs where `proc_pidinfo` returns a short read (macos.rs:309-311).
- Names: `truncate_chars` replaces control characters and clips by **char count** (model.rs:576-604). `Canvas::draw_text` gives each char one cell (canvas.rs:174-191). There is no wcwidth handling, so CJK or emoji names take 2 columns but occupy 1 cell, which shifts the row and desyncs the diff renderer's cursor tracking (canvas.rs:811-823). The test at tests:514-521 asserts char count only.
- Failed collectors: every field is an `Option` and the UI shows OFFLINE/N/A/UNAVAILABLE states (ui.rs:404-413, 1027-1031, 1076-1080, 1169, 1513, 1535, 1595). Gaps: a missing hostname shows a made-up "USS-WORKSTATION"/"USS-ENTERPRISE" (ui.rs:306,650), and the compact primary view draws nothing for a missing disk (ui.rs:415-439).

### unsafe / FFI / panic audit & bounded memory
- About 24 unsafe blocks, all thin libc calls on zeroed `MaybeUninit` buffers with return-code checks. The gethostname buffer is forced to NUL-terminate (mod.rs:321-327). The `ifa_*` pointers are null-checked before dereference (macos.rs:255-262). Almost none of the blocks have SAFETY comments.
- The signal handlers only store to an `AtomicBool`, which is async-signal-safe (terminal.rs:8-14). SIGINT/TERM/HUP/QUIT are installed without SA_RESTART, so `poll` returns EINTR and the quit is handled promptly (205-223).
- `panic = "abort"` (Cargo.toml) is paired with `std::panic::set_hook`, which runs tcsetattr(orig) and writes `\e[0m\e[?25h\e[?1049l` before the previous hook (terminal.rs:114-123). The terminal is restored even under abort. The RAII `Drop` also restores (199-203).
- History uses `push_bounded` with `MAX_HISTORY_LEN` = 64 (sampler.rs:9,282-287); top_processes is truncated to 5 (211). RSS stayed flat at 3,672 KiB over 60 s.
- No TODOs or placeholders (static-scan PLACEHOLDER = 0).

### Test quality & determinism
- 13 tests in tests/lcars_tests.rs, all fixture-driven with no live OS dependency:
  - Parsing: /proc/stat with a CPU delta and a reset (134-162), meminfo with the legacy fallback (164-192), pid stat with parens, spaces and emoji (194-204), uptime/os-release/net-dev (206-232), Mach CPU ticks, VM math and C strings (234-250).
  - Rate math: net hotplug add/remove, 500 ms and 2 s dt, zero and 600 s dt, 32-bit wrap, 64-bit reset (252-316); process vanish and top-5 order (318-355).
  - Layout: 120x36 acceptance checks plus content (357-406); unavailable states (408-423); size sweep from 0x0 to 180x50 × both views × help, plus 80x24 negative space ≥ 25 % (425-450).
  - Rendering: an ASCII-only check plus the SGR families per colour mode (452-484); the cell diff emits only the sync wrapper when frames are identical and contains no `\e[2J` (486-502); input decoding and truncation (504-521).
- Gaps: there is no assertion that the 80x24 tier differs structurally from 120x36, and no display-width test. Overall solid and deterministic.

### Scope discipline
- The process list exists only in `render_*_secondary`. No config files, mouse, themes, plugins or kill/renice.
- Unrequested extras: live `c` colour-cycle and `u` glyph toggles (which do reach required modes), capture/strip-text/bench flags, stardate, `FallbackPosixCollector` for other OSes, and `analyze_visual_acceptance` compiled into the binary. All small; no deduction.
