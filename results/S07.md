## Source inspection notes (file:line)

### Architecture & main loop
- `cmd/lcars/main.go:21-78`: flag parsing and validation, locale-to-ASCII (47-56), `--snapshot` path (57-71), TERM=dumb rejection (72-75), then `app.Run`.
- `internal/app/app.go:24-49`: controller with a sampler goroutine fed by bounded `requests`/`results` channels (cap 1). `accept` (60-74) runs the engine and caps history. `key` (75-97) is a pure state transition and is tested. `Run` (99-223) has the signal setup, terminal session, stdin reader goroutine (117-132), paint closure that diffs against the previous canvas (138-143), and a select loop with the escape/CSI disambiguation timer inline (177-203). The loop is readable but not tiny.
- `internal/ui/view.go`: `Render` (21-38) picks tiny / diagnostic / command / compact. Pure function of `(w,h,State)` that returns a `*Canvas`. `canvas.go`, `shapes.go` (quadrant elbow rasterizer) and `digits.go` are terminal-free.
- `internal/terminal/terminal.go`: raw-mode termios via ioctl. `Session.Close` is guarded by `sync.Once` (69-78).

### OS collector interface & macOS backend
- Interface: `type Collector interface{ Collect(details bool) Raw }` (types.go:54). `Raw` holds per-metric `OK` flags and `Issues`. The pure `Engine.Sample` (types.go:78-146) does all rate and ranking math.
- Linux (`collect_linux.go`): `/proc/stat` (parseCPU 125-152, sums user..steal only so guest is not double counted, idle = idle+iowait), `/proc/uptime`, `/proc/loadavg`, `/proc/meminfo` (used = Total − MemAvailable, 154-175), `syscall.Statfs("/")` (85-90), `/proc/net/dev` excluding `lo` (177-196) keyed by `name/ifindex` (92-98). Per-PID `/proc/<pid>/stat` only when `details` is set (99-121). `AT_CLKTCK` comes from `/proc/self/auxv` (37-56). `parseProcess` uses the last `)`, so names containing `)` are safe (198-220). Field indices are correct (utime 11, stime 12, starttime 19, rss 21 after `)`).
- macOS (`collect_darwin.go`, line by line):
  - Memory: `sysctlbyname("hw.memsize")` + `host_page_size` + `host_statistics64(HOST_VM_INFO64)` with `HOST_VM_INFO64_COUNT` (34-45). Available = (free+inactive)×page, disclosed as an estimate (README:64). The native capture gives 10.2 GiB avail against ref vm_stat (13736+646369)×16 KiB = 10.07 GiB.
  - Swap: `vm.swapusage` → `struct xsw_usage` (47-51). Correct struct and size.
  - Uptime: `kern.boottime` `struct timeval` minus `gettimeofday` (52-57). Loadavg: `getloadavg` (58).
  - Disk: `statfs("/")` (59-64). Used = blocks − bfree counts the whole APFS container (282.9 GiB, which is total − avail). Disclosed.
  - CPU: `host_processor_info(PROCESSOR_CPU_LOAD_INFO)`, summing `CPU_STATE_MAX` ticks per CPU, then `vm_deallocate(info, count*sizeof(integer_t))` and the host port is deallocated (67-85). 32-bit tick wrap shows as unavailable via `CPUPercent` (types.go:67-76).
  - Network: `sysctl{CTL_NET,PF_ROUTE,0,0,NET_RT_IFLIST2,0}` with size slack, walking `if_msghdr2` with `ifm_msglen` bounds checks (100). Only `RTM_IFINFO2` with full struct size is used, loopback is skipped, and records are keyed `if/<index>` (87-110). Output array is sized `size/sizeof(if_msghdr2)+1`, an upper bound on IFINFO2 records. Sound.
  - Processes: `proc_listpids(PROC_ALL_PIDS)` sized plus 4 KiB slack, then `proc_pidinfo(PROC_PIDTASKALLINFO)` with an exact-size check that skips denied or vanished PIDs (112-139). **Bug:** `p->seconds = (pti_total_user + pti_total_system) / 1e9` (133). These fields are in Mach absolute-time units, which on Apple Silicon is ×125/3 ns. Process CPU% therefore reads ~41.7x too low on arm64. It is correct on Intel, where timebase is 1/1. Name comes from `pbi_name` or `pbi_comm` with a bounded `%.*s` (134-135).
  - Go side (161-227): zero-initialized `C.lc_system`, `unsafe.Slice` over the returned counts, `C.free` on each buffer. Nothing is stubbed.
- No CGO-off fallback for darwin. `GOOS=darwin CGO_ENABLED=0` fails with `undefined: metrics.NewCollector` (vet-darwin-arm64.log). This is the documented cgo requirement (README:9,17), and the native macOS build passes.

### Forbidden-subprocess check
- No `exec.Command`/`os/exec`/`syscall.Exec` anywhere in `cmd/` or `internal/` (static-scan SUBPROCESS 0, confirmed by reading). The only `subprocess` use is in the dev script `scripts/verify_terminal.py`, which is a test harness and not part of the app.

### Rate math & robustness edge cases
- Elapsed time: `Raw.At = time.Now()` (monotonic) in both collectors. Rates divide by `raw.At.Sub(previous.At)` (types.go:82,116,128).
- `Rate` (types.go:59-65): elapsed ≤0 or >30 s, or a decreasing counter, gives `Value{}` (unavailable). NaN/Inf are guarded.
- `CPUPercent` (67-76): rejects non-increasing total, decreasing idle, or idle>total.
- Interface churn: only keys present in both samples contribute (113-115). Linux keys carry ifindex and macOS keys carry the interface index, so a recreated interface is not diffed against its predecessor.
- PID churn and reuse: CPU is computed only if the PID exists in the previous sample with the same `Start` and non-decreasing seconds (127). Vanished PIDs drop out naturally. Unreadable `/proc/<pid>/stat` is skipped (collect_linux.go:110-113). On macOS, `proc_pidinfo` short reads are skipped (128).
- Pause and resume force a fresh baseline (app.go:64-67, 86-87).
- Names: `SafeText` (canvas.go:72-89) maps control and format chars to `?`, drops combining marks, and maps runes >U+1FFF or Hangul Jamo to `?`, so 1 rune = 1 column. `ClipText` (97-107) clips by rune with a `~` marker. This is safe, but CJK names become `???`. `Pill` byte-slices labels (canvas.go:123-125), which is only reachable with internal ASCII labels. Host names are clipped (view.go:134, 188).
- Fault isolation: each `/proc` read failure appends to `Issues` and leaves that metric `OK=false` (collect_linux.go:60-66). The UI renders `--`/`unavailable` and a `PARTIAL` status pill (view.go:52-103). Tested by `TestFailedCollectorIsolation` (collect_linux_test.go:56) and `TestMissingValuesAndSafeNames` (view_test.go:130).

### unsafe / FFI / panic audit & bounded memory
- `terminal.go:25-31` raw `SYS_IOCTL`. `TIOCGWINSZ` into `struct{Rows,Cols,X,Y uint16}` matches `struct winsize`. TCGETS/TCSETS (Linux) and TIOCGETA/TIOCSETA (Darwin) use `syscall.Termios`. Sound.
- cgo as audited above. Buffers are size-checked and freed, and ports are deallocated. One semantic FFI bug (Mach-tick units, collect_darwin.go:133).
- Panic: Go panics in the main goroutine run the deferred `session.Close()` (app.go:108-112), so the terminal is restored. A panic inside the sampler goroutine (app.go:34-48, which calls `collector.Collect`) has no `recover` and would terminate the process without restoring termios or the alt screen. The Linux parsers are carefully bounds-checked and fuzzed (`FuzzProcessParser`), so the risk is low but unguarded.
- Bounded: history ≤120 (app.go:69-73, tested to ≤120 len and ≤256 cap at app_test.go:28). Channels have cap 1/8. Canvas is capped at 400x160 (canvas.go:37-38). Only two raw samples are retained (Engine.previous). 60 s RSS is flat.

A sweep over 11 sizes (0x0 to 10000x10000) × diag × ascii × help, with a hostile host and process name containing ESC/OSC/emoji, checks bounds, no control runes and ASCII purity. Diagnostics at 80x24 and 120x36 show all 5 rows and core paging. Single-cell Diff is checked per color mode with no `2J`. DetectColor table. SVG escaping.
- Gap: the 80x24 command layout's simplified content is not asserted.
