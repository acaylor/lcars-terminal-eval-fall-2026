## Source inspection notes (file:line)

### Architecture & main loop
- Layering is documented in `lib.rs:1-9` and matches the code. `run.rs:61-127` is the loop: `present` → poll(stdin + signal self-pipe) → signals → keys → sample-if-due. Frame cadence is 200 ms aligned to the wall clock (`run.rs:26-29`). Sampling runs every interval and does not burst after falling behind (`run.rs:117-125`).
- `Screen` double buffer with `front`/`back` swap (`run.rs:32-59`). Resize drops `front` so the next frame is a full paint, without a clear (`ansi.rs:184-186`).
- `app.rs:89-155`: `Monitor` owns the collector, sampler and UI. It requests the process scan only when the diagnostic view is visible (`app.rs:109-124`).

### OS collector interface & macOS backend
- The trait is at `metrics/mod.rs:181-189`, the factory at `mod.rs:191-204`, and the fallback `unsupported.rs` provides the portable subset.
- Linux (`linux.rs`): `/proc/stat` (busy includes irq/softirq/steal, `:161-189`), `/proc/meminfo` with a fallback for kernels without MemAvailable (`:191-208`), `/proc/net/dev` without lo (`:211-227`), and a scan of `/proc/<pid>/stat` splitting on the last `)` (`:240-251`). Uptime uses `CLOCK_BOOTTIME` (`:152-159`). Net totals are filtered to interfaces backed by a device in `/sys/class/net/*/device`, falling back to all interfaces (`:60-70`). `full_name` extends the 15-byte comm from argv[0] (`:139-149`).
- macOS (`macos.rs`), line by line:
  - CPU: `host_processor_info(PROCESSOR_CPU_LOAD_INFO)`, with a bounds guard `(i+1)*states <= count`. 32-bit ticks are widened to u64, and the buffer is released with `vm_deallocate(count*sizeof(integer_t))` (`:81-116`). A tick wrap gives `checked_sub` → None, so the reading becomes Pending.
  - Memory: `host_statistics64(HOST_VM_INFO64)` with `HOST_VM_INFO64_COUNT`. Used = internal − purgeable + wire + compressor, the Activity Monitor definition (`:118-135`). Total comes from `hw.memsize`.
  - Network: `sysctl{CTL_NET,PF_ROUTE,0,0,NET_RT_IFLIST2,0}` is size-queried, then read with 2 KiB headroom. It walks `ifm_msglen`, checks for `RTM_IFINFO2` and that the bounds cover `size_of::<if_msghdr2>()`, then uses `read_unaligned`. Counters are 64-bit `ifi_ibytes`/`ifi_obytes`; interfaces must be up and non-loopback; names come from `if_indextoname` (`:137-174`).
  - Processes: `proc_listallpids(NULL,0)` for the count, then into a reused `Vec<c_int>` with 64 spare slots (the return is a PID count, used correctly). `proc_pidinfo(PROC_PIDTASKALLINFO)` checks `r != size`, and EPERM/ESRCH are counted as unreadable. CPU time is converted from Mach ticks to ns with `mach_timebase_info`. The start key is `pbi_start_tvsec/usec` (`:176-218`).
  - Uptime is `kern.boottime` (timeval) subtracted from now; swap is `vm.swapusage` (`xsw_usage`); disk is `statvfs` on `/System/Volumes/Data` when present (`:221-231`, `:242`). The OS name comes from `kern.osproductversion`.
  - `sysctl_value<T: Copy>` checks that the returned `len == size_of::<T>()` (`:31-41`). Its callers use only POD types: u64, timeval and xsw_usage.
- Nothing is stubbed. The `#![allow(deprecated)]` (`:6`) only silences libc's deprecation of its Mach bindings in favor of `mach2`, and is explained.

### Forbidden-subprocess check
- `grep Command::new|popen|libc::system|execv` over `src/` and `tests/` finds 0 hits. The two "SUBPROCESS" hits in the static scan are the function name `system(` in `ui/diagnostic.rs:31,119` (false positives). Only the developer script `scripts/pty_harness.py:265` uses `ps`, as a measurement fallback on macOS, which is not part of the app.

### Rate math & robustness edge cases
- Measured dt: `ingest(raw, at)` with `at = epoch.elapsed()` (monotonic `Instant`) (`app.rs:112`). dt < 50 ms or negative keeps the previous rates and the baseline (`sampler.rs:163-171`). `per_second` rejects non-finite dt (`:131-137`). Long gaps average correctly (test `:362-368`).
- Counter decreases are a reset, or a wrap only when a modulus is known and the wrapped delta is ≤ half the range (`:101-117`). CPU tick regressions give None (`:121-129`). A change in core count gives Pending (`:236-238`).
- Interface churn: interfaces are keyed by name, and new ones are skipped until they have a baseline (`:248-256`). PID churn: keyed by `(pid,start)` with `saturating_sub` (`:271-277`). Vanished PIDs count as unreadable (`linux.rs:84-104`, `macos.rs:199-203`).
- Permission: `io::ErrorKind::PermissionDenied` maps to `Missing::Denied` (`mod.rs:44-52`). On macOS, EPERM'd processes are counted as "RESTRICTED".
- Names: `canvas.rs:507-534` clips by `unicode-width` and replaces a wide character that would straddle the edge with a blank. `ellipsize` is width-correct (`:597-616`). Control characters become `?` (`:583-589`). The wide-character continuation guard is at `:478-488`.
- Minor gap: Linux `read_to_string` on `/proc/<pid>/stat` (`linux.rs:87`) fails on a non-UTF-8 comm, so such a process is counted unreadable instead of being shown lossily. This omits rare processes but never crashes. It was not deducted.

### unsafe / FFI / panic audit & bounded memory
- About 49 `unsafe` sites, all thin libc calls. Most have `// SAFETY:` comments; a few (`term.rs:24,40,181`, `macos.rs:98,104`) rely on adjacent comments. The signal handler calls only `write(2)` (`term.rs:148-155`). `restore()` uses `try_lock` so the panic hook cannot deadlock (`term.rs:73-81`).
- Panic path: unwind plus a hook that restores the terminal before the previous hook prints. A `Drop` guard covers normal and error returns. Ctrl-Z restores the terminal before `raise(SIGTSTP)` and re-enters after SIGCONT (`term.rs:114-128`).
- Bounded memory: `Ring` is fixed at 512 (`history.rs:1-42`), the font cache is cleared above 128 entries, the PID vector is reused, and the output buffer is reused (`run.rs:41`). Perf shows a 60 s RSS of 3648→3652 KiB.

### Test quality & determinism
- 77 tests. They include: `sampler.rs:318-466` (11 tests on rates, edge cases, churn and isolation); `linux.rs:264-321` (parsers with fixtures, plus one live sanity sample); `layout.rs:459-506` (tiers, an exhaustive no-overlap/fit sweep, growth); `tests/render.rs` (17 integration tests: no panic at any size in both views, with and without data, negative space ≥ 20%, no process list on primary, required readouts, hostile names, placeholders, help, focus, HOLD, asymmetry, ASCII/mono purity, identical cells across modes, zero-byte unchanged frame, clock-only diff, no orphan wide halves); and encoder, canvas, raster, font, input, color and format unit tests. All are deterministic apart from the one live /proc sanity test.

### Scope discipline
- No config files, mouse, themes, plugins, extra graphics protocols or process actions. The "SCOPE_PROTOCOLS" static-scan hits are terminal-name strings used for color detection (`color.rs:156-161`), not rendering protocols.
